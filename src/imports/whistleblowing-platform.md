Design a modern and minimal web interface for a "Whistleblowing / Ethical Channel Platform" used by companies to receive anonymous reports.

The platform must include the following pages:

1. **Landing Page**

* Title: "Canal Ético"
* Description explaining users can report misconduct anonymously
* Button: "Enviar denuncia"
* Button: "Consultar denuncia"
* Clean corporate design
* Colors: dark blue, white, light gray
* Minimalist professional layout

2. **Submit Report Page**
   Form fields:

* Tipo de denuncia (dropdown)
* Descripción detallada (large textarea)
* Personas involucradas (optional text field)
* Fecha del incidente (date picker)
* Adjuntar archivo (file upload)
* Contraseña para seguimiento (password field)

At the end show a confirmation message:
"Tu denuncia fue registrada correctamente. Guarda tu código de seguimiento."

3. **Tracking Page**
   Form where the user can:

* Enter report code
* Enter password
* Button: "Consultar estado"

4. **Report Status Page**
   Shows:

* Código de denuncia
* Estado (Recibida / En revisión / Cerrada)
* Fecha de creación
* Descripción enviada

5. **Admin Dashboard**

* Table of reports
* Columns:

  * Código
  * Tipo
  * Estado
  * Fecha
  * Acciones

Actions:

* View report
* Download attachment
* Change status

Style:

* Modern SaaS dashboard
* Clean UI
* Responsive layout
* Use cards and tables
* Professional enterprise software design
